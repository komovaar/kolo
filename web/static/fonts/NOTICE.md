# Bundled fonts

Inter Variable v4.1 is vendored unchanged from
https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2.
Its SIL Open Font License is included in `inter-OFL.txt`.

SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`

JetBrains Mono and the legacy Archivo assets retain their included OFL files.
All fonts are served locally by Kolo.
